The code, and what to do with it.

Download

Notespice is free software under the GNU General Public Licence, version 3 or later. Anyone who is given the program is entitled to its source, so here it is, as one archive.

notespice-source.tar.gz 1862 KB, 43 files

Check it against this before you trust it:

sha256  544bef2a5fac6e9a8370f6d3b9d6418dea7ad516ca4beb69b3cb37c34e153857

This archive is the program: the Rust server, the browser frontend, the Dockerfile, the build files and the documentation. The pages of this website are not part of the program and are not in it.

Building it yourself

You need a Rust toolchain, which you can get from rustup, or Docker if you would rather build the image.

tar xzf notespice-source.tar.gz
cd notespice
cargo build --release

The binary lands in target/release/notespice. To build the container image instead:

docker build -t notespice .

The full instructions, including every setting, are on the documentation page.

The ready-made image

If you only want to run Notespice rather than build it, the image is published on GitHub's registry as ghcr.io/gh-lm/notespice.

Browsing the code instead

The archive above is the whole source, and it is replaced whenever a new version is released, so it always matches the current image. If you would rather read it in a browser, the same code is at github.com/gh-lm/notespice. The changelog records what changed in each release.
